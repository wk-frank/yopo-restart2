# 票 B8：柱净空门全拒退路地板与起步斜坡组合（只报数）

B7 给柱净空门加了「全拒时退回离柱面最远候选」的退路，去掉了 B6 的 `PLAN_TIMEOUT`，但在锁步 SITL 上把设定点离柱面只有 0.22–0.25 m（`PillarClearance.gap` 扣除采样保守量后仅 0.02–0.05 m）的贴柱候选交了出去，导致 (a)+0.3 m 的 seed 5 和 (a)+0.5 m 的 seed 6 各撞柱 1 次。同时，起步限加速候选 (a)（3 m/s²、1.5 s）单独开在 L0 `crossing-pillars` 上越过冻结队形误差线 6.0 m（最大 6.29 m），需要配 B5 参考斜坡或 B4 中心斜坡。

本票实现 B7 结论留下的退路地板 `policy_params.b3.pillar_fallback_min_m`，并联合评测 `(a)` + 斜坡（B4/B5）+ 柱门 + 退路地板组合。只报数，所有研究开关默认关。打开柱门/地板即偏离上游（规划器读场景 `p_` 柱几何真值），打开斜坡也标偏离上游。关时摘要、`task_hash` 和飞行轨迹与改前逐位相同。不改 `core/`、`scenes/suite.txt`、场景卡冻结门或 `sitl_bridge.py`，不写 PX4 参数（每趟 `px4_parameters_written == []`，`lockstep.engaged=true`）。逐趟数字在 `b8-fallback-floor-runs.json`。时间均为 2026-11-16 UTC-4，主机 CPU 为 Intel Core Ultra 7 265KF。

## 开关与退路地板逻辑

- 新键 `policy_params.b3.pillar_fallback_min_m`（SITL 用 `YOPO_B2_FIX=floor=<m>` 或简写 `pillar=<m>:<floor>`），默认 `None`（关）。
- 校验规则：必须有限且为正，必须与 `pillar_clearance_m` 同时打开，且满足 `0 < pillar_fallback_min_m <= pillar_clearance_m`（相等时任何未过柱门的候选都过不了地板，退化为 B6 纯硬门）。
- `PillarClearance.gap(motion, speed_limit)` 与 `allows` 共用同一标尺：按 0.02 s 采样整条拟合轨迹到 `p_` 柱面的最小距离减机体半径 0.35 m，再减 `v_max × dt/2`（`v_max=20` 时约 0.20 m）的采样保守量。因此 `gap` 地板 0.2 m / 0.3 m 对应采样轨迹表面净空约 ≥ 0.40 m / ≥ 0.50 m。
- 当本批候选全部未过 `pillar_clearance_m` 时，`PillarClearance.fallback` 先取 `gap` 最大的候选（并列取原排序靠前者）：
  - 若 `gap >= pillar_fallback_min_m`：与 B7 相同，进入 `_as_plan`，通过则记 `PILLAR_FALLBACK`（`fallbacks += 1`）。
  - 若连最远候选也 `< pillar_fallback_min_m`：记 `floor_blocked += 1` 并返回 `None`，`_take_motions` 不提交贴柱退路，落回 `CrossingFleet._planner` 已有的无解分支——机体仍在运动且运动学刹车段过净空门与契约时提交 `BRAKE_ONLY`，否则记 `CLEARANCE_SKIP` 保持上一份已提交安全计划。
- 单测 `tests/test_l0_b8_fallback_floor.py`（7 个用例）覆盖：缺省关与显式 `None` 同机逐位一致、非法参数与 `YOPO_B2_FIX` 组合解析、地板上下分流、触发运动学刹车 `BRAKE_ONLY` 与悬停保持 `CLEARANCE_SKIP`、短跑偏离标记，以及森林卡无 `p_` 柱子报错。

## 结论

1. `pillar_fallback_min_m` 按设计工作：全拒且最远候选仍低于地板时不交 `PILLAR_FALLBACK`，落入运动学刹车 `BRAKE_ONLY` 或保持旧计划 `CLEARANCE_SKIP`。锁步 SITL 两臂 20 趟碰撞 **0**（B7 为 2），设定点最小净空从 0.22–0.25 m 抬到 **0.44 m / 0.64 m**，并在 `0.3/0.2` 档 seed 0、seed 7 上实测验证了「地板拦截 → 刹车 → 下一拍脱困到达」。
2. 与 `(a)` + B5 参考斜坡（`reframp=3`）或 B4 中心斜坡（`ramp=3`）组合后，L0 `crossing-pillars` 10/10 通过全部冻结门（碰撞 0，编队误差 p95 最大 4.41 m / 4.31 m ≤ 6.0 m）。
3. **所有研究开关保持默认关。** 柱门与退路地板仍依赖读场景 `p_` 柱几何真值（偏离上游），且当飞机停在柱前持续产不出过地板候选时仍会以安全 `PLAN_TIMEOUT` 收尾，不能根治 PX4 起步与横移跟踪滞后。若要在实验臂里同时消除贴柱撞柱并兼顾通过率，`launch=3:1.5,reframp=3,pillar=0.3,floor=0.2`（L0 10/10 过门、SITL 9/10 零碰撞）是当前最均衡的一组对照参数。
