# 阶段 C 停车距离和控制限速

每块板用当天的可靠净视距（RCH）、响应延迟、制动距离上界和误差余量计算可用速度。计划准入检查候选轨迹的速度上界及当前里程计速度。跟踪每周期重算可用速度，并用当前实测速度检查剩余停距。

## 制动数据

`StoppingConstraints` 接收 `response_delay_s`、`effective_decel_mps2`、`margin_m` 和 `measured_brake_points`。每个实测档由速度上界和该档制动距离上界组成。档位按速度升序排列，速度区间从上一档上界的下一速度开始，到本档上界为止。该区间内使用本档距离。测量距离上界随档位保持非递减，并涵盖当前载荷、运行模式和测量误差。最高档为已校准速度上限。

停车所需净距为响应期间行进距离、制动距离及余量之和。带实测档时，制动项取实测上界与恒减速度模型的较大值。主机数值用例使用恒减速度模型。实体板验收使用每日逐机实测档和当日 RCH。

## 判定与接收证据

- 计划目标速度须在按 0.01 m/s 向下取整的限速以内，且当前运动有剩余停车空间。
- 跟踪复核后，速度要求超限时使用符合新约束的参考。若当前速度也超限、停距不足或速度未校准，按控制权限撤销当前前进计划。选用制动尾前核验其几何、邻机分离及当前停车余量。
- `StoppingDecision.evidence()` 保存输入、标定档、计划和当前所需净距、剩余余量、限速与处置。用会话及控制序号对齐飞控接收端的时刻、权限和实际收到的指令。当前停距余量为负或缺证时，单独记录停车距离未通过。

参考用例取 RCH 3.00 m、延迟 0.15 s、减速度 2.0 m/s²、余量 0.70 m。精确模型上限约 2.747950 m/s，可用指令上限 2.74 m/s。2.75 m/s 需 3.003125 m。3.00 m/s 需 3.40 m。
