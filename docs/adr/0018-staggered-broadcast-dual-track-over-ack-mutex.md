# 三机实机采用对时错峰单向多项式广播与双轨占用并集

编号是 0018。拆到三块独立 Orin Nano 后，障碍段的机间协同采用对时后的固定相位槽错峰重规划（例如 10 Hz 下 `0 / 33.3 / 66.7 ms`）、本机通过包含完整制动尾的分离检查后生效并单向广播紧凑五次多项式系数包（`< 350 B`，`yopo_l0/swarm_udp.py`），接收端在网络时延窗口 $\delta_{\text{net}}$ 内取邻机“上一条已生效计划 + 新收到计划（均含制动尾与末端保持）”的**双轨占用并集（Dual-Track Occupancy Union）**做欧氏分离校验，不采用双向 `PROPOSE / ACK` 确认锁。

## Context

在 10–15 Hz 近距深度避障中，若要求冲突区域的新计划必须等待无线邻机返回 ACK 并到达共同生效时刻才切换，单向瞬时丢包或重传退避会直接拉长响应延迟（消耗宝贵的 D435 可靠净视距停距预算），甚至导致逼近障碍物的飞机因缺票而死锁。同时，直接跨 Wi-Fi 发送 `float64(N, 4)` 离散轨迹采样（`3.2–6.4 KB`）会触发 IP 分片放大丢包率。

## Consequences

- 每次重规划无线载荷压缩至单帧 MTU 以内（`< 350 B`），本机避障零握手等待延迟。
- 双轨只能表示已收到的轨迹。即使最近一次报文新鲜，下一次改轨也可能单向丢失。提交共享空间新计划时，还须用每个邻机同会话、同坐标系的带时标实测位置和可验证的物理速度上界，检查直至本机执行和制动结束时的整个可达域。误差预算涵盖时钟、定位、跟踪及曲线采样。
- 任一邻机缺报、观测过期、重启隔离或边界相交即拒绝新计划。降级沿已验证的制动尾执行。重新加入前须核验身份及坐标，收到新会话的新观测和计划。运行期持续复核和真实无线失效验收见阶段 C。
