# 三机实机采用对时错峰单向多项式广播与双轨占用并集

编号是 0018。拆到三块独立 Orin Nano 后，障碍段的机间协同采用对时后的固定相位槽错峰重规划（例如 10 Hz 下 `0 / 33.3 / 66.7 ms`）、本机立即生效并单向广播紧凑五次多项式系数包（`< 350 B`，`yopo_l0/swarm_udp.py`），接收端在网络时延窗口 $\delta_{\text{net}}$ 内取邻机“上一条已生效计划 + 新收到计划（均含制动尾与末端保持）”的**双轨占用并集（Dual-Track Occupancy Union）**做欧氏分离校验，不采用双向 `PROPOSE / ACK` 确认锁。

## Context

在 10–15 Hz 近距深度避障中，若要求冲突区域的新计划必须等待无线邻机返回 ACK 并到达共同生效时刻才切换，单向瞬时丢包或重传退避会直接拉长响应延迟（消耗宝贵的 D435 可靠净视距停距预算），甚至导致逼近障碍物的飞机因缺票而死锁。同时，直接跨 Wi-Fi 发送 `float64(N, 4)` 离散轨迹采样（`3.2–6.4 KB`）会触发 IP 分片放大丢包率。

## Consequences

- 每次重规划无线载荷压缩至单帧 MTU 以内（`< 350 B`），本机避障零握手等待延迟。
- 邻机单向失联时按最后有效轨迹与通信龄速度上界线性膨胀禁入包络；同一机号变更 `session_id` 重启时自动隔离该邻机，直至人工重新核对身份与坐标。
